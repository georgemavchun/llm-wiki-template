# Wiki

This directory is the knowledge base. Open it as an Obsidian vault if you like a graph view; the agent maintains it either way.

- `raw/inbox/` — put new sources here
- `raw/` — cleared sources (never edited)
- `sources/`, `entities/`, `concepts/`, `synthesis/` — agent-written pages
- `INDEX.md` — where everything is
- `LOG.md` — what happened when
- `CLAUDE.md` — the schema every agent must follow

Common requests to the agent: `ingest the inbox`, `quick note: …`, `what does the wiki say about …`, `crystallize this`, `lint the wiki`.

The repository README explains setup, privacy and the skills in detail.
